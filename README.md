# Juliandunn Tools

## How do I install these formulae?

`brew install juliandunn/tools/<formula>`

Or `brew tap juliandunn/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "juliandunn/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
